# Creative Portfolio — Illustrator & Visual Designer

A modern, responsive portfolio website showcasing digital illustration, character design, and visual storytelling work. Built with React, TypeScript, and Tailwind CSS.

## Features

- 🎨 **Modern Design** - Clean and elegant portfolio layout with smooth animations
- 📱 **Responsive** - Fully responsive design that works on all devices
- ⚡ **Fast Performance** - Built with Vite for optimal performance
- 🎭 **Interactive UI** - Smooth transitions and hover effects
- 🌙 **Dark Theme** - Beautiful dark mode design
- ♿ **Accessible** - Built with accessibility in mind using Radix UI components

## Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **UI Components**: Radix UI
- **Form Handling**: React Hook Form
- **Routing**: React Router
- **Icons**: Lucide React

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Mostafa-SAID7/p-designer.git
cd p-designer
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:8080/`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run build:dev` - Build in development mode
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run test` - Run tests
- `npm run test:watch` - Run tests in watch mode
